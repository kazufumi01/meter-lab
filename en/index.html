Reference

How each meter is implemented here, and where it is useful in practice.

VU IEC 60268-17 / ANSI C16.5

A full-wave-rectified average with needle inertia (a second-order system) on top. It rises slowly and moves much like our sense of how “big” a sound is. The scale is calibrated so a sine reads its RMS value.

Rise
99% in 300 ms, 1–1.5% overshoot
Implementation
ζ = 0.80, ωn = 13.2 rad/s (measured 0.30 s / +1.4%)
Reference
0 VU = +4 dBu (hardware). In a DAW it is usually set to −18 dBFS (EBU R68) or −20 dBFS (SMPTE)
Scale
Proportional to voltage (−20 to +3 VU); the low end is cramped and hard to read
Where it helps:Setting input level into analog-modelled plugins (1176, LA-2A, tape, consoles). Their sweet spot is designed around 0 VU, so setting the gain before them so the VU swings around 0 makes them distort the way the model intends.

Sample Peak dBFS

The largest absolute sample value. Attack is instant and it never misses even a single-sample peak — but it does not look between the samples.

Attack
0 ms (max within each block)
Release
12 dB/s (display), 1.5 s hold
0 dBFS
The largest value fixed-point audio can hold. Inside 32-bit float you can go over safely, but it clips on export
Where it helps:Watching for digital clipping and checking track headroom. It has almost nothing to do with perceived loudness, so do not use it to balance faders.

True Peak ITU-R BS.1770 Annex 2 · dBTP

Oversamples 4× or more to estimate the peak of the waveform reconstructed after D/A conversion. Even with a limiter holding samples at −0.1 dBFS, the reconstructed waveform can go over 0 dBFS.

Implementation
4× polyphase FIR (48 taps, Blackman-Harris window)
Error
about −0.2 dB on the fs/4, 45° test (roughly within the standard’s tolerance)
Streaming target
−1 dBTP or lower, because lossy decoding adds even more peak
Where it helps:The very end of the master chain — the basis for a limiter’s true-peak mode and ceiling. The louder the master, the wider the gap between true peak and sample peak tends to be.

RMS windowed root mean square

The square root of the mean square over a time window. It is proportional to energy, so it is more clearly defined than VU, but it has no frequency weighting — the more low end a sound has, the quieter it sounds for its number.

Window
50 / 300 / 1000 / 3000 ms (rectangular)
Sine
−3.01 dB below its peak; AES-17 adds +3.01 dB so the two match
Where it helps:A reference for understanding compressor detection (the RMS window in Pro-C 3 or Unisum, for example). Around 300 ms behaves much like VU; 50 ms reacts strongly to transients.

PPM approximation of IEC 60268-10 Type II

A quasi-peak meter. Its few-ms attack integration reads very short transients slightly low, and its slow return is easy to follow by eye. It has long been used for level control in broadcasting.

Attack
τ = 4.8 ms (about −4 dB on a 10 ms burst)
Return
24 dB / 2.8 s (≈ 8.6 dB/s)
Display
shown in dBFS here; a real BBC-type meter is marked 1–7
Where it helps:Peak control for vocals and dialogue. Less twitchy than sample peak and less sluggish than VU, it is a good middle view for spotting breaths and sibilants that jump out.

LUFS ITU-R BS.1770 / EBU R128

A mean square weighted toward human hearing with K-weighting (a +4 dB high shelf and a high-pass around 38 Hz), summed across channels. Differences are in LU. Integrated uses gating to leave out silence and very quiet passages.

Momentary
400 ms window
Short-term
3 s window
Integrated
400 ms blocks (75% overlap), absolute gate −70 LUFS, relative gate −10 LU
LRA
spread between the 10th and 95th percentile of short-term (relative gate −20 LU, Tech 3342)
Typical
Spotify / YouTube −14, Apple Music −16, broadcast −23 LUFS
Where it helps:Predicting how much streaming normalisation will turn you down, and matching loudness across songs and an album. Going above −14 just gets turned down by the service, so decide it as a trade-off against PLR (dynamic headroom).

LRA EBU Tech 3342 · LU

How much the loudness moves between sections of a song: the spread between the 10th and 95th percentile of the short-term (3 s) values. Fade-outs and one-off hits are trimmed off by the percentiles.

Input
the whole history of short-term loudness (3 s window)
Gate
absolute −70 LUFS, relative −20 LU (looser than the −10 LU of Integrated)
Changed by
arrangement, automation, song structure
Not changed by
fast-attack compression (invisible to a 3 s window)
Typical
EDM / mainstream 3–6 / indie 5–9 / dream pop, post-rock 8–15 LU
Where it helps:Checking that bus or master processing has not flattened the difference between verse and chorus. Pushing the master limiter harder barely moves LRA, while heavy long-release compression on the master bus lowers it — a handy way to tell which process is doing what.

PLR Peak to Loudness Ratio · LU

Max true peak − integrated loudness: the gap between the song’s peak and its average loudness, showing how much transient life is left. It drops almost dB-for-dB with the loudness you gain from limiting.

Example
−1 dBTP / −8 LUFS → 7 LU, −1 dBTP / −13 LUFS → 12 LU
After normalisation
matched to −14 LUFS, the peak becomes −14 + PLR dBTP
Typical
6–8 squashed master / 9–11 modern pop / 12–14 indie / 15+ acoustic
Note
set by the single biggest peak in the song, so one stray peak inflates it
Where it helps:Predicting how a master will sound on streaming. A −8 LUFS master is turned down to −14 and its peaks land around −7 dBTP, so its attack sits further back than a −13 LUFS / PLR 12 master. If PLR looks too good, find where the max true peak is and tame just that spot with clip gain.
